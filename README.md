# Dra. Juliane Klobukoski

Site institucional (landing page) — estética avançada e harmonização facial.

## Stack

- Vite
- React + TypeScript
- Tailwind CSS v4

## Desenvolvimento

```sh
npm i
npm run dev
```

## Build

```sh
npm run build
```

## Deploy

Projeto estático, pronto para deploy na [Vercel](https://vercel.com): importe este repositório como um novo projeto (framework preset "Vite") e o deploy é automático a cada push.
